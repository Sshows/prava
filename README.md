# Право / Практика

Квиз по 6 лекциям основ права Казахстана. Все 154 вопроса из двух исходных HTML-тестов: 122 РК1 + 32 дополнительных, без сокращений и удаления похожих вопросов.

Тренировка и экзамен, выбор лекций и источника, Fisher-Yates для вопросов и ответов, результаты и повтор ошибок. История хранится локально в браузере.

## Запуск

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm test
npm run build
```

Развёртывание: Vercel, Vite, output `dist`. Вопросы и ключи перенесены из предоставленных учебных материалов.
