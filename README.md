# Право / Практика

122 исходных вопроса РК1 из шести лекций. Выбор лекций и подборок: статьи и числа; правильный ответ самый длинный; остальные. Подборки не пересекаются.

В тренировке ошибка возвращается через два других вопроса; ошибки сохраняются сразу и доступны отдельной кнопкой. Экзамен без повторов, с разбором в конце.

Запуск: npm ci, npm run dev. Проверка: npm test, npm run build. Vercel: Vite, dist.
